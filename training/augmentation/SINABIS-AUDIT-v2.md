## Data preparation contract

The new profile is an exact-artifact CC BY source registry, separate from the accepted FDEC-008 MIT/Apache allowlist. That legacy guard, all existing source denials and both Codex pack restrictions remain unchanged. `training_boundary.assert_training_source` routes only the exact Sinabis identity to this profile; it does not allow generic CC BY datasets or unfiltered rows through legacy ingestion. `sinabis_source.prepare` rechecks current evidence and snapshots the exact approved bytes before decoding. No model/provider API is invoked.

Preparation extracts source `text`, never quoted-history `body`, and carries exact source rows, complete case lineage and the shared Oil-family identity. It consolidates exact text duplicates, checks near-duplicate components, and quarantines connected components with incomplete or unresolved origin/thread metadata. The detector uses Unicode NFKC/casefold alphanumeric five-character shingles and exact integer Jaccard >=80%; resource limits fail explicitly. This is a declared lexical detector, not proof that semantic paraphrases cannot overlap.

Sinabis supplies no validated canonical targets. Every dimension stays missing with supervision disabled. `sinabis-mapping-v1.json` defines the twelve topics, four priorities, independent spam/phishing/malware assessments and four actions as an annotation-review contract; it does not generate per-message ground truth. An external independently permitted reviewer must provide and validate actual labels before supervised training. The schema supports 29 language codes, while the pinned 10K profile admits only its four observed languages. It neither translates messages nor claims 29-language data coverage or accuracy.

All Oil editions remain one source-family cohort. Any proposed role assignment that divides a thread, duplicate component or that family across train/validation/test is rejected. No actual train/test partition is created from this single source. The existing FDEC-012 rights/consent/split gate remains mandatory and currently does not admit this new CC BY profile; do not fabricate an FDEC-009 receipt or claim this preparatory projection has passed that gate. Later reviewed integration must support the exact profile and independent label/consent evidence before real training. These remaining gates do not block acceptance of the generator/preparation software.

Sinabis 10M remains **not admitted**: complete artifact and row-origin inspection has not been performed, and its generic generator routes are not resolved. Its 29-language metadata is an extension target only. No large archive download, corpus redistribution, purchase, model training, Mac switch or model publication is performed by this task.
