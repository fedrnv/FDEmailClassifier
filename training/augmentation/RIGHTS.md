# Synthetic source rights assessment, 2026-11-20

The parallel phrase catalog was drafted with OpenAI Codex in this development
session. It is not human-authored source data, imported mail, or an existing
third-party email corpus. Project source-code licensing under LICENSE/NOTICE
does not resolve contractual restrictions on using these phrases for model
training. No production dataset or trained model is approved by this assessment.

The [OpenAI Services Agreement](https://openai.com/policies/services-agreement/)
assigns output rights subject to its other restrictions. Its classifier exception
is conditioned on not distributing the model or making it commercially available
to third parties. The applicable account agreement and any bespoke permission
have not been established here. That exception cannot simply be assumed to cover
this project's intended public model distribution.

The [OpenAI Usage Policies](https://openai.com/policies/usage-policies/), effective
2026-11-20, restrict preparation or supply of training material for substitute
models, including later reuse of evaluation outputs, while retaining express
agreement exceptions and permitted software development. Therefore this catalog
is admitted only as a local **software fixture** for testing generation plumbing.
It must not become training data, training signals or a publication dataset.
No attempt to relabel or strip provenance changes those restrictions.

`augmentation-rights-v1.json` binds the exact catalog and original source notices;
`augmentation-sources-v1.json` binds that audit. Their sole allowed purpose is
`software_fixture`. Runtime generation/translation reject commercial_training
and evaluation for this pack before artifact creation. Receipts and every sample
explicitly mark training as disallowed. Fixture labels test the software contract
and must not be supplied as training supervision to a model.

FDEC-011 remains incomplete until a suitable source pack and its applicable
training/model-distribution rights are actually established. A human-authored
synthetic parallel catalog with documented permissions, or provider-specific
permission applicable to this use, can supply that missing input. New packs
require an explicit repository audit and registry binding; there is no command
line rights override. This does not claim that any provider restriction is
resolved merely by changing a license field or by running locally.

No real mail, address book, personal identifier, third-party model weight, remote
generation/translation call or training run was used to construct these fixtures.
The phrase resource is generator code, not exported message rows. Rendered
messages live only in ignored private run directories. Redistribution is a
separate review for every pack and remains unapproved here.
