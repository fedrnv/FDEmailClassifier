# Stock Qwen baseline (FDEC-015)

This is local baseline software, not a measured baseline. AC-01 is incomplete
until the stock model has actually evaluated an admitted multilingual held-out
corpus and produced a verified report. Software tests use counterfactual policies,
technical tokens and protocol doubles. No actual language model consumes those
fixtures, their texts or their labels.

Run the focused software checks from the repository root:

```powershell
powershell -NoProfile -File training/baseline/test-baseline.ps1
.venv/ingestion/Scripts/python.exe training/baseline/baseline.py preflight
```

`preflight` only reports availability. It neither admits data nor claims metrics.
The default interpreter is the existing pinned ingestion environment. The tests
do not install a transformer runtime, download model tensors or train anything.

## Actual evaluation inputs

An independently prepared private data package must supply all of these:

- Exact independently audited, non-OpenAI source ingestion runs. Every source
  needs the existing origin policy and both commercial-training/evaluation
  grants. The source bytes, normalized text and original annotations are replayed
  through the unchanged ingestion verifier. Fixture packs remain denied.
- A valid split inventory, split receipt/manifest and currently activated signed
  consent. Existing source/thread/family/exact/near-duplicate grouping is reused;
  no row-level fallback or split-policy override exists in this CLI.
- Independent gold annotations, never generated by this code or copied from
  automatically mapped source labels without review. The JSON object has schema
  `fdec-baseline-annotations/v1` and `rows`. Each row contains `record_id`, BCP-47
  style `language`, a classification-v1 `classification`, and boolean `mask`
  entries for `topics`, `priority`, `spam`, `phishing`, `malware`, `action`.
  The rows must be exactly the test partition, with at least two independently
  verified languages. Mask only genuinely reviewed known heads; a fallback
  `review` action is not automatically ground truth. Unknown gold is not a
  negative. Language tags are declarations, not automatic language verification.
- A current operator-controlled `training/data/baseline-review/current.json`.
  Schema `fdec-signed-baseline-review/v1` contains `payload` and `hmac_sha256`.
  Payload schema `fdec-baseline-label-review/v1` binds canonical inventory,
  signed consent and split-receipt SHA-256, exact annotation-file SHA-256,
  `reviewer_kind` = `independently-reviewed-non-openai`, independent evidence
  SHA-256, `issued_at` and `valid_until` (UTC seconds). The HMAC-SHA256 input is
  UTF-8 `fdec-baseline-label-review/v1` + NUL + canonical payload JSON, using the
  existing protected 32-byte consent-authority key. No automatic signing or
  approval command is provided. This is an operator attestation: the protected
  key/anchor are trust roots; a signature cannot prove real-world authorship or
  annotation truth. Keep the underlying independent review evidence privately.
- An offline local stock snapshot matching `qwen-stock-v1.json`, containing
  exactly its eight named files, without links or extra executable artifacts.
  No automatic download or remote code is allowed. See `MODEL-AUDIT.md`.

The actual evaluation command requires explicit opt-in. Paths below are private
operator-supplied artifacts, not files shipped by the repository:

```powershell
.venv/ingestion/Scripts/python.exe training/baseline/baseline.py evaluate --opt-in `
  --inventory training/data/approved/inventory.json `
  --consent training/data/approved/consent.json `
  --split-dir training/outputs/approved-split `
  --annotations training/data/approved/independent-gold.json `
  --source-run training/data/approved/source-1 `
  --source-run training/data/approved/source-2 `
  --source-run training/data/approved/source-3 `
  --model-dir models/downloads/qwen-stock-v1 `
  --output-dir training/outputs/baseline-run-001
```

Provision `FDEC_CONSENT_KEY` through the existing private authority process;
never print, commit or include it in command arguments. Neither policy roots,
current authority anchors nor fake-model adapters can be overridden by CLI flags.
Insufficient/malformed input rejects before model initialization. Existing output
directories cannot be overwritten. Reports contain aggregates and identities,
never email text, prompts, raw model responses or input paths. A receipt is
written last; failed publication rolls back only the newly owned directory.
Authority is checked before each record and publication; it remains a point-in-time
check, not a guarantee of future consent.

## Measurement definition and limits

The fixed inference instructions in `prompt.py` are advisory inference code,
not training email content or gold labels. The tokenizer's non-thinking switch is
mandatory. The baseline uses CPU float32, one thread, seed zero, greedy decoding,
2048 input tokens and 512 output tokens. Oversize inputs abort instead of silently
truncating a benchmark. Only generated suffix tokens are decoded; missing EOS,
reasoning, Markdown, duplicated JSON keys or schema violations are invalid outputs.
Greedy decoding is a reproducibility choice, not Qwen's recommended sampled
quality setting. Reproducibility is scoped to the recorded environment, not a
promise of identical results across arbitrary devices or library versions.

Metrics include per-language coverage, scalar head accuracy, topic exact-set
accuracy, micro F1 and macro F1 over gold-supported topics. Counts and macro
denominator are included. Missing gold is masked. Invalid/unknown/abstained model
outputs remain in eligible denominators as failures. Zero-eligible scores are
null. This small baseline metric set does not replace the later evaluation suite,
calibration or security acceptance tasks. No confidence or phishing-quality
guarantee is inferred from software tests or an unmeasured model.

Current unavailable inputs and the AC matrix are recorded in FDEC-015 evidence.
Sinabis preparation alone supplies neither independent canonical gold nor the
three independent cohorts required by the unchanged grouped-split policy.
