# FDEmailClassifier logo resources

The official monochrome logo is a rounded-square **E**. Use the SVG files as scalable originals:

- [logo-light.svg](logo-light.svg) — charcoal tile / white E for light UI backgrounds.
- [logo-dark.svg](logo-dark.svg) — light gray tile / charcoal E for dark UI backgrounds.

The visual identity is original project artwork. Keep logo geometry consistent across both themes; do not stretch or change proportions. Suggested exports: 512, 256, 128, 64 and 32 px square PNGs. The logo is separate from third-party model/dataset licensing. A raster reference illustration was generated during design review; the SVG files here are editable implementations of the selected monochrome concept.
