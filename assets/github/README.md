# Social preview source

social-preview.svg is an original geometric/text composition created for FDEC-072.
No external artwork, logo, model output or third-party font files are embedded.
System Arial/sans-serif is used at render time. Original source is Apache-2.0.
social-preview.png is the 1280x640 rendered upload asset. The card marks early
development and planned SDKs; no accuracy or released-model claim is made.

Upload PNG through repository Settings > General > Social preview. Committing the
image alone does not set the GitHub card. Inspect the generated card before AC-03
can be accepted. GitHub recommends PNG/JPG/GIF under 1 MB, ideally 1280x640:
https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview
