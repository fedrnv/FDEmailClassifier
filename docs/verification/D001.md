# D001 local integration gate

Run `powershell -NoProfile -File scripts/verification/D001.ps1 -ExpectedSource
<40-character-commit>` from the owning local turn. Tracked source must match that
commit before and after every stage. Unrelated untracked IDE state is not an input.
This command is never reachable from a hosted workflow.

The gate covers D001's actual foundation interfaces: workspace consumers and
isolated binding, strict Serde and JSON Schema output, original-source governance
and locked dependency licenses, immutable task graph/shared admission and identity
migration, and README/architecture/preview entry links. Negative cases cover
malformed/unsafe output, invalid server arguments, unknown package, missing/corrupt
licenses, unresolved distribution, stale readiness/rules/migrations, incomplete
dependencies, duplicate identities/requests and unreviewed hosted workflows.

The child scripts and exact commands are visible in the gate source. cargo-deny
checks both lockfile graphs. npm/Ajv verifies JSON Schema independently of Serde;
its pinned local CLI may use the npm cache. No models, datasets or raw emails are
used. Toolchains: pinned Rust 1.98.0, cargo-deny, Node/npm with ajv-cli 5.0.0 and
PowerShell. Current supported verification environment is Windows x86_64 MSVC.

Manual current-state review additionally checks architectural SDK ownership and
advisory-only behavior, metadata/card readback evidence, SVG/PNG visual acceptance
and the distinction between local source changes and public settings. Existing
unchanged hash-bound visual evidence may be reused. No unavailable future SDK,
backend, REST, concurrency or model-quality tests count as passing evidence.

DEVELOPMENT.md delegates exact local commands to each task once paths exist;
this task-scoped document supplies the D001 command within the gate's accepted
docs/verification scope without editing the normative root contract. Gate evidence
binds the actual candidate SHA, tool/environment identities, commands and outcomes.
Any functional change invalidates affected results. FDEC-007 performs independent
review of the exact tested source, with separate immutable request/result artifacts.
